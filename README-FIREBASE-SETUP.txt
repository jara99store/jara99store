===================================================================
 JARA 99 STORE — Firebase Setup Guide (বাংলায়, ধাপে ধাপে)
===================================================================
এটা করলে Admin Panel থেকে product/category/combo যোগ করলেই সাথে সাথে
পুরো ওয়েবসাইটে সবার জন্য LIVE হয়ে যাবে — আলাদা কোনো ফাইল আপলোড করতে হবে না।
সম্পূর্ণ ফ্রি, সময় লাগবে ১০-১৫ মিনিট। শুধু একটা Google/Gmail account লাগবে।

-------------------------------------------------------------------
ধাপ ১: Firebase প্রজেক্ট তৈরি করুন
-------------------------------------------------------------------
1. ব্রাউজারে যান: https://console.firebase.google.com
2. আপনার Gmail দিয়ে লগইন করুন।
3. "Add project" / "Create a project" বাটনে ক্লিক করুন।
4. প্রজেক্টের নাম দিন, যেমন: jara99store
5. Google Analytics-এর অপশন আসলে "Enable"/"Disable" যেকোনোটা বেছে "Continue" করুন।
6. প্রজেক্ট তৈরি হলে "Continue" চাপুন।

-------------------------------------------------------------------
ধাপ ২: Firestore Database চালু করুন
-------------------------------------------------------------------
1. বাম পাশের মেনু থেকে "Build" > "Firestore Database" এ যান।
2. "Create database" ক্লিক করুন।
3. Location হিসেবে যেকোনো কাছের (যেমন asia-south1 / Mumbai) সিলেক্ট করুন।
4. "Start in test mode" বেছে "Enable" করুন (এটা শুরু করার জন্য যথেষ্ট,
   পরে চাইলে security rules আরও কড়া করে দেওয়া যাবে)।

-------------------------------------------------------------------
ধাপ ৩: Authentication (লগইন সিস্টেম) চালু করুন
-------------------------------------------------------------------
1. বাম মেনু থেকে "Build" > "Authentication" এ যান।
2. "Get started" ক্লিক করুন।
3. "Sign-in method" ট্যাব থেকে "Email/Password" সিলেক্ট করে "Enable" করুন, তারপর "Save"।
4. এবার "Users" ট্যাবে যান, "Add user" ক্লিক করুন।
5. একটা Email আর Password দিন — এটাই হবে Admin Panel-এর শেয়ার্ড লগইন
   (যেমন: admin@jara99store.com / আপনার পছন্দের একটা শক্তিশালী password)।
   এই একই Email+Password সবাইকে (যাদের product upload করার দরকার) দিয়ে দিন।

-------------------------------------------------------------------
ধাপ ৪: Web App যোগ করে Config কপি করুন
-------------------------------------------------------------------
1. বাম মেনুর উপরে গিয়ার আইকনে ক্লিক করে "Project settings" এ যান।
2. নিচের দিকে "Your apps" সেকশনে "</>" (Web) আইকনে ক্লিক করুন।
3. একটা App nickname দিন (যেমন: jara99store-web), "Register app" ক্লিক করুন।
4. এখন যে কোড দেখাবে তাতে "firebaseConfig = { ... }" এর ভেতরের তথ্যগুলো
   (apiKey, authDomain, projectId, storageBucket, messagingSenderId, appId)
   কপি করে নিন।

-------------------------------------------------------------------
ধাপ ৫: আমাদের ওয়েবসাইটের firebase-config.js ফাইলে বসান
-------------------------------------------------------------------
1. ওয়েবসাইট ফোল্ডারের "firebase-config.js" ফাইলটি খুলুন।
2. PASTE_YOUR_... লেখা জায়গাগুলোতে ধাপ ৪-এ কপি করা মানগুলো বসান।
3. ফাইলটি সেভ করে হোস্টিং-এ (আগের ফাইলগুলোর পাশে) আপলোড করে দিন।

-------------------------------------------------------------------
ধাপ ৬: প্রথমবার ডাটা Import করুন
-------------------------------------------------------------------
1. ওয়েবসাইটে "admin.html" এ যান (নিচে ফুটারে "Admin Login" লিংক আছে)।
2. ধাপ ৩-এ তৈরি করা Email/Password দিয়ে লগইন করুন।
3. উপরে "🟢 Live Mode (Firebase)" দেখালে বুঝবেন ঠিকমতো কানেক্ট হয়েছে।
4. সবার নিচে "🌱 প্রথমবার — Default Data Firebase-এ Import করুন" বাটন
   দেখতে পাবেন — এতে ক্লিক করুন। এতে আগের সব ক্যাটাগরি/প্রোডাক্ট/কম্বো
   Firebase-এ চলে যাবে।
5. এরপর থেকে যা কিছু Add/Delete করবেন তা সাথে সাথে Live হয়ে যাবে —
   কোনো ডাউনলোড/আপলোডের দরকার নেই।

-------------------------------------------------------------------
নিরাপত্তা নোট
-------------------------------------------------------------------
- Test mode-এ ৩০ দিন পর Firestore-এর write বন্ধ হয়ে যেতে পারে (Firebase-এর
  ডিফল্ট নিয়ম)। তখন "Firestore Database" > "Rules" ট্যাবে গিয়ে নিচের rule
  বসিয়ে "Publish" করে দিন (এটা করলে শুধু লগইন করা অ্যাডমিনরাই লিখতে
  পারবে, সবাই শুধু দেখতে পারবে):

    rules_version = '2';
    service cloud.firestore {
      match /databases/{database}/documents {
        match /{document=**} {
          allow read: if true;
          allow write: if request.auth != null;
        }
      }
    }

- Admin Email/Password শুধু বিশ্বাসযোগ্য মানুষদের সাথে শেয়ার করুন।

সরাসরি দেখিয়ে দেওয়া যাবে।
